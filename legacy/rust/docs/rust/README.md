# Archived Rust documentation

The files in this folder describe the retired Rust server, its former static
explorer, PostgreSQL/Redis storage, S3 CSV exporter, and historical provider
experiments. They are retained for traceability and are not current Python API
documentation.

- [Deprecated Rust source](../../aipriceaction/)
- [Current Python API](../../../../aipriceaction-api/README.md)
- [Current provider and storage details](../../../../docs/DATA_SOURCES.md)
- [Production migration status](../../../../aipriceaction-api/MIGRATION.md)

The former Rust project was moved as a whole to `legacy/rust/aipriceaction/`.
The code-path examples inside old documents use their original project-relative
paths unless a document explicitly says otherwise.
